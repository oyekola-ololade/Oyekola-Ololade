## Evidence vocabulary

- **CURRENT / VERIFIED** — current artifact with appropriate test/execution evidence.
- **CURRENT / PARTIAL** — current implementation exists but significant paths remain unverified/incomplete.
- **UNDER REPAIR** — checked-in implementation has known defects.
- **HISTORICAL** — real older architecture/workflow/build evidence.
- **PROPOSED** — design/repair target; not implemented.
- **REFERENCED / ORIGINAL NOT LOCATED** — version/patch is supported by lineage records but the standalone source was not recovered.
- **PLACEHOLDER** — visible reserved location for evidence that does not yet exist; never counted as evidence.

## Media policy

Only a project's **current/latest implemented state** receives empty demo/screenshot placeholders. Historical versions do not get fake media folders. Existing genuine current media is used instead of placeholders.
